Dataflow — Ten Stages

Every recording takes the same road.

From raw audio bytes to a HUMAN / AI verdict, each stage is deterministic and testable in isolation — the exact sequence implemented in preprocessing.py, features.py, model.py, and infer.py.

Signal — audio_input · preprocessing · chunking
01

Audio Input

Decode .wav / .mp3 / .flac / .m4a / .ogg, resample to 16kHz, fold to mono.

02

Preprocessing

Trim long silent stretches with librosa.effects.trim at a 30dB threshold.

03

Chunking

Fixed 5.0s windows, 0.5 overlap fraction, zero-padded when a clip runs short.

Spectral — fft · mel filter bank · normalization
04

FFT Analysis

Short-time FFT, window n_fft=1024, hop 256 — raw frequency content per frame.

05

Mel Filter Bank

128 Mel bands mapped across 0–8kHz, matching perceptual pitch spacing.

06

Mel Spectrogram

Power spectrogram (power=2.0) converted to dB — log compression for stable training.

07

Normalization

z = (x − μ) / (σ + ε) — per-chunk standardization, immune to recording loudness.

Learning — cnn · classification
08

CNN Feature Learning

Four ConvBlocks (16→32→64→128 channels) extract local-to-abstract spectrogram patterns.

09

Classification

Global average pool → dropout 0.3 → linear layer → HUMAN / AI logits.

Verdict — aggregation
10

Score Aggregation

Per-chunk AI-probabilities combine via mean / median / trimmed-mean / vote into one recording-level score, compared against a 0.5 decision threshold.

Architecture

A compact CNN, treating sound as an image.

The normalized Mel spectrogram is fed in as a single-channel image. Global average pooling keeps the classifier agnostic to chunk length or band count, so the pipeline stays flexible as config.py changes.

Inference

Run it on your own audio.

Point infer.py at a checkpoint and a file — it chunks, scores, and aggregates automatically, printing a per-chunk breakdown alongside the final call.

terminal
# install dependencies
pip install -r requirements.txt

# train on your own labeled dataset
python train.py --data_root ./data --out model.pt

# score a single recording
python infer.py --model model.pt --audio sample.wav
